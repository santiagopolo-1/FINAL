# FINAL
Entrega final de Santiago Polo para Taller Multimedia 1
El repositorio busca recapitular la biografía de Madonna y proveer un análisis de su discografía.

Inicialmente se trabajó en la página principal, mezclando elementos de la entrega de bestario y elementos nuevos.
Posteriormente, se elaboró una plantilla para los sitios de cada álbum a partir de la página de American Life.
Se hizo este proceso 16 veces, con información que me sé de memoria a partir de videos de YouTube y entrevistas de Madonna.
Adicionalmente, investigué las posiciones de los listados y las canciones en las páginas de Billboard y UK Official Singles Chart.
Las hovers, colores y tipografías se hicieron principalmente en .css (exceptuando la página principal que cuenta con un script.js y una librería .css dentro de este).
Para cada página se procuró utilizar tipografías distintas en los títulos, todas estas descargadas de Google Fonts.
