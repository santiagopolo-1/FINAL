# FINAL
Entrega final de Santiago Polo para Taller Multimedia 1
El repositorio busca recapitular la biografía de Madonna y proveer un análisis de su discografía.

Inicialmente se trabajó en la página principal, mezclando elementos de la entrega de bestario y elementos nuevos.
Posteriormente, se elaboró una plantilla para los sitios de cada álbum a partir de la página de American Life.
